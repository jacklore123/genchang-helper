# 使用说明（老师版）

## 一、电脑上怎么用

1. 把 `跟唱助手` 整个文件夹拷到班级电脑（U 盘直接拷，不用安装）
2. 双击文件夹里的 **跟唱助手.exe**
3. 会弹出一个窗口，标题栏写着「跟唱助手」，没有地址栏和标签页，就像普通软件

窗口长这样：

```
┌─────────────────────────────────────┐
│ 歌名                       ☰ 歌曲   │
├─────────────────────────────────────┤
│                                     │
│              🎤                     │
│            原  唱                    │
│        点一下 → 切换伴奏             │   ← 点这里！
│                                     │
├─────────────────────────────────────┤
│ 1:23 ━━━━━●━━━━━━━━━━━ 3:31        │   ← 拖进度
│                                     │
│   B标记    ▶    1.0速度              │   ← 播放 / A-B / 变速
├─────────────────────────────────────┤
│ 伴奏 ──●──  人声 ──●──              │   ← 混音比例
│ [原唱][伴奏][跟唱][人声][A-B][预备]  │   ← 模式
└─────────────────────────────────────┘
```

**上课怎么用：**

| 场景 | 操作 |
|---|---|
| 先让学生听原唱 | 点大按钮，变成 🎤 **原唱** |
| 学会了，切伴奏 | 再点一下大按钮，变成 🎹 **伴奏**（进度不会跳） |
| 有一句总唱不好 | 播到那句开头按 `B标记` 定 A 点，到结尾再按一次定 B 点，自动循环 |
| 想跟着弱原唱唱 | 点 `跟唱`，把「人声」滑块调到 20% 左右 |
| 只听旋律 | 点 `人声` |
| 太快跟不上 | 点 `速度`，切到 0.8× 或 0.7×（音高不变） |
| 起唱前要准备 | 点 `预备`，选 4 秒或 8 秒，按下播放会先数拍 |

**键盘快捷键**：`空格` 播放/暂停　`Tab` 切换原唱/伴奏　`A` 打 A-B 点　`←/→` 快退快进 5 秒

## 二、换歌 / 加歌

窗口里点 **☰ 歌曲 → ＋ 导入新歌**，选一首歌的音频或视频文件，等 1–3 分钟。
程序会在本地把原唱分离成「伴奏」和「人声」，然后这首歌就出现在歌曲库里。

- 支持格式：mp3、wav、flac、m4a、aac、ogg，以及 mp4/mkv 等视频（自动抽音轨）
- 分好的文件存在 `跟唱助手.exe` 同级的 `library/<歌名>/` 里
- **整个文件夹拷到别的电脑，歌曲库一起带走**，不用重新处理

**如果你手上有官方伴奏**（音质比 AI 分离好得多），告诉我，我可以用
「原唱 + 官方伴奏」自动对齐的模式打包，完全不损失音质。

## 三、手机上怎么装

1. 把 `跟唱助手.apk` 发到学生手机（微信 / QQ / 数据线都行）
2. 手机上点开这个文件 → 允许「安装未知来源应用」→ 安装
3. 桌面会出现一个紫荆花图标的「跟唱助手」

手机上的操作和电脑完全一样。

**手机上导入歌曲**：点 ☰ 歌曲 → ＋ 导入新歌 → 先选【原唱】文件 → 再选【伴奏】文件 → 起个名字。
（手机不做 AI 分离，所以要自己准备一对原唱+伴奏；分离请在电脑上做。）

## 四、常见问题

**Q：杀毒软件报警？**
A：这是自己打包的绿色软件，没有数字签名，部分杀软会提示。加信任即可。

**Q：exe 双击没反应？**
A：第一次启动要解压，等 3–5 秒。如果还不行，看看文件夹是否被杀软删掉了 `_internal`。

**Q：切原唱/伴奏的时候声音会跳吗？**
A：不会。两条音轨是同一份录音对齐出来的，实测 0 采样偏差，切换只是 45 毫秒的淡入淡出。

**Q：能让每台电脑都装一份吗？**
A：可以，整个文件夹是绿色的，拷过去就能用。
