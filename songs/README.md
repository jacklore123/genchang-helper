# songs/ —— 待处理的原始歌曲

把歌曲放这里，然后：

```bash
python tools/make_pack.py --scan
```

或者直接 push 到 GitHub，工作流会自动跑并把跟唱包放到 Artifacts 里。

## 命名规则

每个歌一个子目录：

```
songs/
├── 紫荆花盛开/
│   ├── voice.mp3      # 原唱（必需）—— 也可以叫 vocal.mp3 / 原唱.mp3 / 任意名字
│   └── accomp.mp3     # 官方伴奏（可选）—— 叫 accomp / inst / 伴奏 开头
└── 另一首歌/
    └── 歌曲.mp3        # 只有原唱 → 自动 AI 分离出伴奏
```

- 目录里有 `accomp*`（或 `inst*`、`伴奏*`）→ 走**官方伴奏模式**：不跑 AI，直接对齐，音质最好
- 只有原唱 → 走 **AI 分离模式**：本地跑 UVR-MDX-NET 把人声抽掉

## ⚠️ 版权提醒

这个目录已经在 `.gitignore` 里排除了，**放这里的音频不会被提交到仓库**。

如果你是 fork 后想提交到公开仓库，请务必保持这个排除规则 ——
把有版权的歌曲提交到公开仓库属于侵权，会被 DMCA 下架。
